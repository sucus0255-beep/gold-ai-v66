Gold AI V6.6 — Android PWA (ฟรี / READ ONLY)

วิธีใช้งานแบบไม่ต้องเปิดคอมพิวเตอร์:
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub Repository แบบ Public (ห้ามอัปโหลดรหัสผ่านหรือ Token)
2. ไปที่ Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save
3. รอให้ได้ HTTPS URL เช่น https://ชื่อผู้ใช้.github.io/ชื่อรีโป/
4. เปิด URL ด้วย Chrome บน Android > เมนู ⋮ > Install app / เพิ่มไปยังหน้าจอหลัก
5. จากนั้นเปิดแอปด้วย Wi-Fi หรือ 4G/5G ได้ โดยไม่ต้องเปิดคอมพิวเตอร์

ข้อเท็จจริงเกี่ยวกับข้อมูล:
- ราคาสปอต XAU/USD ใช้ https://api.gold-api.com/price/XAU (ไม่มีคีย์ในโค้ด) และต้องมีเวลาอัปเดตที่ API ระบุจึงแสดงราคา
- แท่งเทียนใช้ https://api.binance.com/api/v3/klines?symbol=PAXGUSDT ... เป็น PAXG/USDT ไม่ใช่ XAUUSD ของ MT5
- ไม่สามารถยืนยันความพร้อมใช้งาน CORS, ข้อจำกัดประเทศ, การเปลี่ยนแปลง API หรือการใช้งานฟรีได้จากสภาพแวดล้อมนี้
- หาก API ปิดกั้นคำขอ จะขึ้นสถานะ NO DATA / ข้อผิดพลาด ไม่แสดงข้อมูลจำลองเป็นข้อมูลจริง
- ระบบไม่ดึงข้อมูลเมื่อปิดแอป ไม่มีการแจ้งเตือน Push ขณะปิดแอป ไม่มีเซิร์ฟเวอร์เบื้องหลัง
- ออฟไลน์เปิดตัวแอปจากแคชได้ แต่ไม่สามารถรับข้อมูลตลาดใหม่
- ไม่มีการส่งคำสั่งซื้อขาย; การวิเคราะห์เป็นเพียงสถิติจากข้อมูลย้อนหลัง
- PWA ต้องโฮสต์ผ่าน HTTPS เพื่อให้ติดตั้งและใช้ service worker ได้; file:// ไม่พอ
